# Dataset-backed misconception catalogue

The active labelbook is Eedi Misconceptions Graph v1.0 at revision `2ae0839debf73c0ce7dd6578d8ea8b99e7be8631`: 8,117 original IDs and texts. No replacement label names were authored.

See [catalogue manifest](eedi_catalogue_manifest.json) for source hashes, CC BY 4.0 attribution, original-ID link validation and 384-dimensional embeddings. Kaggle IDs use a separate namespace; no integer-index equivalence is assumed.

A runtime rule returns a candidate ID; working and source evidence are required before confirmation. Persistence requires repeated attempts.
