## Is P true?

It is. The argument above can be modified to prove this.

We start with (iii). Clearly, (iii) implies (ii). Does (ii) imply (i)? Not necessarily because (ii) does not state the number of pairs with repeating factors. For example, if the number of such pairs is two — say $\overline { { \mathcal { f } } } , \mathcal { f }$ and (g, g) — what can we say about the number of factors? In such a case, the given number will have an even number of factors.

However, a number cannot have more than one factor pair with repeating factors. Thus, a square number necessarily has an odd number of factors. Hence Statement P is also true.

In this example, ‘n is a perfect square’ and ‘n has an odd number of factors’ imply each other.
