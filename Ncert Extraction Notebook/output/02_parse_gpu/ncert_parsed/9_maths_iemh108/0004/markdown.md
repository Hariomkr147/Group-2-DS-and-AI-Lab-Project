## Think and Reflect

Why is it useful to have an explicit formula for the $n ^ { t h }$ term of a sequence?

Using an explicit formula, we can find the $2 0 ^ { \mathrm { t h } }$ term, the $5 3 ^ { \mathrm { r d } }$ term, the $3 0 0 ^ { \mathrm { t h } }$ term or any term of the sequence directly by just substituting the appropriate value of n. If we have an explicit formula, we can find the value of a term without having to know the value of previous terms!
