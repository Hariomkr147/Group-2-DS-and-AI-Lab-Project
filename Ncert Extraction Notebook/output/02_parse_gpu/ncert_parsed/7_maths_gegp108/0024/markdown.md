2. For each of the questions below, choose the expression that describes the solution. Then simplify it.

(a) Maria bought 8 m of lace to decorate the bags she made for school. She used $\frac{1}{4}$ m for each bag and finished the lace. How many bags did she decorate? (i) $\begin{array}{c}8 \times \frac{1}{4} \\8 \div \frac{1}{4}\end{array}$ (ii) $\frac { 1 } { 8 } \times \frac { 1 } { 4 }$ (iii) (iv) ${ \frac { 1 } { 4 } } \div 8$

(b) $\frac { 1 } { 2 }$ meter of ribbon is used to make 8 badges. What is the length of the ribbon used for each badge? (i) $8 \times \frac{1}{2}$ (ii) $\frac { 1 } { 2 } \div \frac { 1 } { 8 }$ (iii) $8 \div \frac { 1 } { 2 }$ (iv) ${ \frac { 1 } { 2 } } \div 8$

(c) A baker needs $\frac { 1 } { 6 } \mathrm { k g }$ of flour to make one loaf of bread. He has 5 kg of flour. How many loaves of bread can he make? (i) $5 \times { \frac { 1 } { 6 } }$ (ii) ${ \frac { 1 } { 6 } } \div 5$ (iii) $5 \div \frac { 1 } { 6 }$ (iv) $5 \times 6$
