**Non-uniqueness of decimal representations.** Just as $1 = { \frac { 1 0 } { 1 0 } } = { \frac { 1 0 0 } { 1 0 0 } } ,$ rational numbers can have two decimal forms. Any terminating decimal has an alternative with repeating 9s: 1.000 … = 0.999 …, 2.47000 … = 2.46999 ….

Is it not surprising that 0.999 … = 1? Many would have guessed that it is slightly less than 1.
