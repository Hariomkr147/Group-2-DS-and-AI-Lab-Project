Since one digit is non-repeating, we multiply by $1 0 ^ { 1 } = 1 0$ and obtain $1 0 x = 1 . \overline { { 6 } }$

**Step 3:** Now, to move one full repeating cycle (1 digit repeating), we multiply by $1 0 ^ { 1 } = 1 0$ again and get 100x = 16.6.

**Step 4:** Subtracting the first shifted equation from the second, we get,

$100x - 10x = 16.\overline{6} - 1.\overline{6}$ or 90x = 15. Thus, $X = \frac{15}{90} = \frac{1}{6}$
