When we combine all integers and all fractions (both positive and negative), we get the set of **Rational Numbers**, denoted by $\mathbb { Q }$ (for quotient).

A **rational number** is defined as any number that can be expressed in the form $\frac { p } { q } ,$ where $p$ and $q$ are integers and $q \neq 0$

We must make some important observations at this stage.

All rational numbers can be written in the form $\frac{p}{q},$ where $p$ and $q$ are integers and $q \neq 0 .$ . For example, 5 and –10 can be written as $\frac { 5 } { 1 }$ and $\frac { - 1 0 } { 1 }$ , respectively. What this means is that the rational numbers also include the natural numbers, whole numbers and integers.

Rational numbers do not have a unique representation in the form ${ \frac { p } { q } } ,$ , where p and $q$ are integers and $q   \neq   0$ .
