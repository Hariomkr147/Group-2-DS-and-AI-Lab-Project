Sometimes when the numerical values of $x _ { i }$ and $f _ { i }$ are large, finding the product of $x _ { i }$ and $f _ { i }$ becomes tedious and time consuming. So, for such situations, let us think of a method of reducing these calculations.

We can do nothing with the $f _ { i } ^ { \flat } \mathrm { { S } }$ , but we can change each $x _ { i }$ to a smaller number so that our calculations become easy. How do we do this? What about subtracting a fixed number from each of these $x _ { i } ^ {   ^ { \prime } } \mathrm { S }   _ { \cdot } ^ { \mathrm { ? } }$ Let us try this method.

The first step is to choose one among the $x _ { i } ^ { \prime }$ s as the assumed mean, and denote it by $^ { \circ } a ^ { \prime }$ . Also, to further reduce our calculation work, we may take $^ \circ a ^ { \prime }$ to be that $x _ { i }$ which lies in the centre of $x_{_1},x_{_2},\ldots,x_{_n}$ . So, we can choose $a = 4 7 . 5$ or $a = 6 2 . 5$ . Let us choose $a = 4 7 . 5$

The next step is to find the difference $d _ { i }$ between a and each of the $x _ { i } ^ { \mathrm { ~ \prime ~ } } \mathrm { S }$ , that is, the **deviation** of $^ { \circ } a ^ { \prime }$ from each of the $x _ { i } ^ { \mathrm { ~ \prime ~ } } \mathrm { S }$

i.e.,

$$
d _ { _ i } = x _ { _ i } - a = x _ { _ i } - 4 7 . 5
