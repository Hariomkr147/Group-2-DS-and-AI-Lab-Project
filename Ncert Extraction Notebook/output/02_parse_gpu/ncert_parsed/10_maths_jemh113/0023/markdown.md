To find this class, we find the cumulative frequencies of all the classes and $\frac { n } { 2 }$ We now locate the class whose cumulative frequency is greater than (and nearest to) $\frac { n } { 2 }$ This is called the median class. Therefore, 60 – 70 is the **median class**.

After finding the median class, we use the following formula for calculating the median.

$$
\mathrm{Media} = l + \left(\frac{\frac{n}{2} - \mathrm{cf}}{f}\right) \times h,
$$

where l = lower limit of median class,

n = number of observations,

cf = cumulative frequency of class preceding the median class,

f = frequency of median class,

h = class size (assuming class size to be equal).
