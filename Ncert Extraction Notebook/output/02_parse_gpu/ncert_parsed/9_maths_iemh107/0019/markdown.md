## Chapter Summary

z Probability is a measurement of the likelihood of an event.

Probability is expressed on a scale from 0 (indicating impossibility) to 1 (indicating certainty), representing the likelihood of an event occurring. The probability of an event E is denoted as P(E), where $0 \leq \mathbb { P } ( \mathbb { E } ) \leq 1$

Experimental probability is determined by conducting an experiment and is calculated as:

Number of times the event occurred Experimental Probability Total number of trials

Theoretical probability is based on all possible outcomes in a fair situation, assuming each is equally likely:

Theoretical Probability of an event A is

$$
\mathrm{P}(\mathrm{A})=\frac{\text { Number of failures } \text { outcomes }}{\text { Number of possible outcomes }}
$$

z A sample space is the list of all possible outcomes of a random experiment. It is represented as a set $\mathrm{S} = \mathrm{function}_{1},$ outcome …, outcome }.

An event is any one or a group of possible outcomes from a random experiment. It is like picking results or outcomes from all that could happen.

Tree diagrams help us to list and visualise all possible outcomes of a random experiment. They also help us calculate probabilities of events related to random experiments.
