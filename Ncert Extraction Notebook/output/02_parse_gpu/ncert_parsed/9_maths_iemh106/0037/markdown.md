## Chapter Summary

π is the constant circumference to diameter ratio for all circles, and is approximately equal to $\frac { 2 2 } { 7 }$ or 3.14.

The circumference of a circle is given by $\mathsf { C } = 2 \pi r _ { \mathrm { i } }$ , where r is the radius of the circle.

• The arc length of a circle is given by $l = 2 \pi r \times \frac { \Theta ^ { \circ } } { 3 6 0 ^ { \circ } }$ , where θ is the central angle.

• The area of a triangle is given by $\mathrm { A } = { \frac { 1 } { 2 } }$ base times height.

• Heron’s formula for the area of a triangle in terms of its sides a, b, c:

$\mathrm{area} = \sqrt{s(s - a)(s - b)(s - c)}$ . where $s = s = \frac{1}{2}(a + b + c).$

• The area of a circle is given by $A = \pi r^{2}$

Estimates for π: Archimedes: $3 \frac { 1 0 } { 7 1 } < \pi < 3 \frac { 1 } { 7 } ;$ Chongzhi: $\pi \; \approx \; \frac { 3 5 5 } { 1 1 3 } ;$ Āryabhaṭa: $\pi \; \approx \; 3.1416;$ Mādhava’s exact formula: $\pi = 4 \left( 1 - \frac{1}{3} + \frac{1}{5} - \frac{1}{7} + \cdots \right)$

• π is an irrational number.

• The area of a sector of a circle is given by $\mathrm{area} = \pi r^2 \times \frac{\theta^\circ}{360^\circ}$ where θ is the central angle.
