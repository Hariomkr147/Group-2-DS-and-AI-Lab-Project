Since it is a direct proportion, we know that

$$
{ \frac { 5 } { 3 } }   \times   x   =   1   \times   1
$$

$$
x = { \frac { \frac { 1 \times 1 } { 5 } } { \frac { 5 } { 3 } } } = { \frac { \frac { 1 } { 5 } } { \frac { 3 } { 3 } } } = { \frac { 3 } { 5 } } .
$$

If they cut the vegetables together, they will finish in $\frac{3}{5}$ hours.
