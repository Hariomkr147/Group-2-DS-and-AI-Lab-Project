## SUMMARY

Ratios in the form a : b : c : d : … indicate that for every a units of the first quantity, there are b units of the second quantity, c units of the third quantity, and so on.

If x is divided into many parts in the ratio p : q : r : s : …, then the quantity of the first part is $\chi \times \frac{p}{(p + q + r + s + \cdots)}$ , the quantity of the second part is $X \times { \frac { q } { (   p + q + r + s + \cdots ) } }$ , and so on.

Two quantities are directly proportional when they both change by the same factor, and their quotient remains the same. For example, if x and y are two quantities that are directly proportional, and $( x _ { 1 } , x _ { 2 } , x _ { 3 } , \ldots )$ and $( y _ { 1 } , y _ { 2 } , y _ { 3 } , \ldots )$ are the corresponding values of x and y, then $\frac{x_{1}}{y_{1}}=\frac{x_{2}}{y_{2}}=\frac{x_{3}}{y_{3}}=\cdots=k,$ where k is a constant.

Quantities are inversely proportional if, when one quantity changes by a factor n, the other quantity changes by the inverse $\frac { 1 } { n }$ . For example, if x and y are two quantities that are inversely proportional, and $\left( X_{1},X_{2},X_{3},\cdots \right)$ and $( y _ { 1 } , y _ { 2 } , y _ { 3 } , \ldots )$ are the corresponding values of x and y, then $X_{1}y_{1}=X_{2}y_{2}=X_{3}y_{3}=\cdots=n,$ where n is a constant.
