**So, we can find integers** r **and** $s \left( \neq 0 \right)$ **such that** $\left[ { \sqrt { 2 } } = { \frac { r } { s } } \right.$

**Suppose** r **and** s **have a common factor other than 1. Then, we divide by the common factor to get** ${ \sqrt { 2 } } = { \frac { a } { b } }$ , where a and b **are coprime.**

**So, we can write** $a = 2 c$ **for some integer** c.

**Substituting for** a, we get $2 b ^ { 2 } = 4 c ^ { 2 }$ , that is, $b ^ { 2 } = 2 c ^ { 2 }$

**This means that 2 divides** $b ^ { 2 } ,$ **, and so 2 divides** b **(again using Theorem 1.2 with** $\hat { p }   =   2 )$ **Therefore,** a **and** b **have at least 2 as a common factor.**

**But this contradicts the fact that** a **and** b **have no common factors other than 1.**

**This contradiction has arisen because of our incorrect assumption that** $\sqrt { 2 }$ **is rational. So, we conclude that** $\sqrt { 2 }$ **is irrational.**
