## 11.2 Summary

In this chapter, you have studied the following points :

**1.** Length of an arc of a sector of a circle with radius r and angle with degree measure   is $\frac { \dot { \boldsymbol { \theta } } } { 3 6 0 } \times 2 \pi r .$

**2.** Area of a sector of a circle with radius r and angle with degree measure   is $\frac { \theta } { 3 6 0 } \times \pi   r ^ { 2 }$

**3.** Area of segment of a circle = Area of the corresponding sector – Area of the corresponding triangle.
