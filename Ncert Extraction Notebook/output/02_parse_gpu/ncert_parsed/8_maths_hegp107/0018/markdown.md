**Volume**

$$

**Temperature**

Temperature conversion between Fahrenheit and Celsius is a bit more complicated. $0^{\circ}C = 32\;^{\circ} F$ , and

$$
\mathrm{Fahrenheiit} = \frac{9}{5} \times \mathrm{Celsius} + 32
$$

and

$$
Celsius = \frac{5}{9} \times ( Fahreniet -32)
$$

For example, $2 5   ^ { \circ } \mathrm { C }$ is $7 7   ^ { \circ } \mathrm { F } .$
