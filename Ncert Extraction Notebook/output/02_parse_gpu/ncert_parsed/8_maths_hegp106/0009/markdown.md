## Multiply 3874 by 101.

Let us take a 4-digit number dcba.

$$
d c b a \times 1 0 1 = d c b a \times ( 1 0 0 + 1 ) = d c b a \times 1 0 0 + d c b a .
$$

This becomes

$$
\frac{d\quad c\quad b\quad a\quad o}{d\quad c\quad b}\quad a\quad a
$$

Use this to multiply $3 8 7 4 \times 1 0 1$ in one line.

Such methods of applying the distributive property to easily multiply two numbers were discussed extensively in the ancient mathematical works of Brahmagupta (628 CE), Sridharacharya (750 CE) and Bhaskaracharya (Lilavati, 1150 CE).
