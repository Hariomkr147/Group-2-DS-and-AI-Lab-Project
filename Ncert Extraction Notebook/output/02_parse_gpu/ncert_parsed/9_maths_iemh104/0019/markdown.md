To find $( x y + x z + y z )$ , we need to use the identity

We get 100 = 38 + 2 (xy + xz + yz). Thus xy + xz + yz = 31.

**Example 16:** Simplify the rational expression $\frac{x^{2}-7x+12}{5x^{2}+5x-100}$ assuming that $5x^{2} + 5x - 100 \ne 0$

In order to simplify this rational expression, we need to cancel the common factors between the expressions in the numerator and denominator.

We will need to use algebraic identities to simplify this rational expression.

First, let us look at the numerator $X^{2}-7X^{\prime \prime}+12$ . We need to find a and b such that $a \pm b = - 7$ and $ab = 12.$ Can you think of two such numbers? They are – 3 and – 4. Factor the expression, we get $x^{2}-7x+12=(x-3)(x-4)$

Now let us look at the denominator $5 \bar { x } ^ { 2 } + 5 x - 1 0 0$ .
