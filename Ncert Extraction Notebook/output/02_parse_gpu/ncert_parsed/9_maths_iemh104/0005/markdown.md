## 4.3 Factorisation of Algebraic Expressions Using Identities

The identity $(a + b)^{2} = a^{2} + 2ab + b^{2}$ can also be used to find factors of some algebraic expressions.

**Example 5:** Consider the algebraic expression $x ^ { 2 } + 4 x + 4$

We observe that

$x ^ { 2 } = ( x ) ^ { 2 } ,   4 = 2 ^ { 2 }$ and 4x = 2(2)(x).

Hence, $x^{2}+4x+4=x^{2}+2(x)(2)+2^{2}$ can be compared with $a ^ { 2 }   +   2 ( a ) ( b )   +   b ^ { 2 } ,$ where a = x and b = 2.

We conclude that $x^{2}+4x+4=(x+2)^{2}$ . Therefore, we can say that $( x + 2 )$ is a factor of $x^{2} + 4x \pm 4.$

**Example 6:** Let us try to find factors of another algebraic expression: 36x<sup>2</sup> + 12x + 1.

Writing this in the form $a^{2} \pm 2ab + b^{2}$ we get

$$
36x^{2}+12x+1=(6x)^{2}+2(6x)(1)+1^{2}
$$

where a = 6x and b = 1. Therefore, $36x^{2} + 12x + 1 = (6x + 1)^{2}.$

Thus (6x + 1) is a factor of $36x^{2} + 12x + 1$
