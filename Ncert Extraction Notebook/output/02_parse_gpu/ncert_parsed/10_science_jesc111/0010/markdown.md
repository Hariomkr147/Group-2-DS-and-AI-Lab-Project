## Example 11.4

**The potential difference between the terminals of an electric heater is 60 V when it draws a current of 4 A from the source. What current will the heater draw if the potential difference is increased to 120 V? Solution**

We are given, potential difference $V = 6 0   \mathrm { V } ,$ current $I   =   4   \mathrm { A }$

**According to Ohm’s law,** $R=\frac{V}{I}=\frac{60\  V }{4\  A }=15\ \Omega$

**When the potential difference is increased to 120 V the current is given by**

$$
{ \mathrm { c u r r e n t } } = { \frac { V } { R } } = { \frac { 1 2 0 { \mathrm { ~ V ~ } } } { 1 5 \; \Omega } } = 8 { \mathrm { ~ A ~ } } .
$$

**The current through the heater becomes 8 A.**

## Example 11.6

**A wire of given material having length l and area of cross-section A has a resistance of 4** Ω. **What would be the resistance of another wire of the same material having length l/2 and area of cross-section 2A? Solution**

**For first wire**

$$
R_{1} = \rho \frac{l}{A} = 4\Omega
$$

**Now for second wire**

$$
R_{2} = \rho \frac{l/2}{2A} = \frac{1}{4} \rho \frac{l}{A}
$$

$$
R _ { _ 2 } = \frac { 1 } { 4 } \quad R _ { _ L }
$$

$$
R _ { 2 } { = } 1 \Omega
$$

**The resistance of the new wire is 1**Ω.
