(iv) $a_{2}-a_{1}=1-1=0$ $a_{3}-a_{2}=1-1=0$ $a_{4}-a_{3}=2-1=1$

Here, $a_{_2}-a_{_1}=a_{_3}-a_{_2}\ne a_{_4}-a_{_3}.$

So, the given list of numbers does not form an AP.
