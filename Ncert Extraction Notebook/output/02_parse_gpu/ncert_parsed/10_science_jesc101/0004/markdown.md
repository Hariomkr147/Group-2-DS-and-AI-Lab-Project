**Step I: To balance a chemical equation, first draw boxes around each formula. Do not change anything inside the boxes while balancing the equation.**

$$
\boxed { \mathrm { F e } } + \boxed { \mathrm { H } _ { 2 } \mathrm { O } } \rightarrow \boxed { \mathrm { F e } _ { 3 } \mathrm { O } _ { 4 } } + \boxed { \mathrm { H } _ { 2 } }\tag{1.5}
$$

**Step II: List the number of atoms of different elements present in the unbalanced equation (1.5).**

**Step III: It is often convenient to start balancing with the compound that contains the maximum number of atoms. It may be a reactant or a product. In that compound, select the element which has the maximum** number of atoms. Using these criteria, we select $\mathrm { F e _ { 3 } O _ { 4 } }$ **and the element oxygen in it. There are four oxygen atoms on the RHS and only one on the LHS.**

**To balance the oxygen atoms –**

<table><tbody><tr><td rowspan="2">Atoms of oxygen</td><td rowspan="2">In reactants</td><td rowspan="2">In products</td></tr><tr></tr><tr><td>(i) Initial</td><td>1 (in H<sub>2</sub>O)</td><td>4 (in Fe<sub>3</sub>O<sub>4</sub>)</td></tr><tr><td>(ii) To balance</td><td>1×4</td><td>4</td></tr></tbody></table>

**To equalise the number of atoms, it must be remembered that we cannot alter the formulae of the compounds or elements involved in the reactions. For example, to balance oxygen atoms we can put coefficient** ‘4’ as 4 $\begin{array}{c} H _{2} O \end{array}$ and not $\mathrm{H_{2}O_{4}\bar{or}(H_{2}O)_{4}}$ **. Now the partly balanced equation becomes –**

$$
\boxed{ Fe } + 4 \boxed{ H _2 O } \Longrightarrow \boxed{ Fe _3 O _4} + \boxed{ H _2}\tag{1.6}
$$

**(partly balanced equation)**

**Step IV: Fe and H atoms are still not balanced. Pick any of these elements to proceed further. Let us balance hydrogen atoms in the partly balanced equation.**

**To equalise the number of H atoms, make the number of molecules of hydrogen as four on the RHS.**

<table><tbody><tr><td rowspan="2">Atoms of hydrogen</td><td rowspan="2">In reactants</td><td rowspan="2">In products</td></tr><tr></tr><tr><td>(i) Initial</td><td>8 (in 4 H<sub>2</sub>O)</td><td>2 (in H<sub>2</sub>)</td></tr><tr><td>(ii) To balance</td><td>8</td><td>2 × 4</td></tr></tbody></table>

**The equation would be –**

$$
\begin{array}{l}\boxed{ Fe } + \ 4 \boxed{ H _2 O } \rightarrow \boxed{ Fe _3 O _4} + \ 4 \boxed{ H _2}\end{array}\tag{1.7}
$$

**(partly balanced equation)**
