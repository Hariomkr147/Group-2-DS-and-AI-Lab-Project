In (1) and (2) above, is F not the same as ‘not $\mathrm { E } ^ { \prime } ?$ Yes, it is. We denote the event ‘not $\mathrm { E ^ { \prime } }$ by $\overline { { \overline { { \mathrm { E } } } } }$

In general, it is true that for an event $\mathbf { E } _ { z }$

$$
\mathbf{P}(\mathbf{E}) = \mathbf{1} - \mathbf{P}(\mathbf{E})
$$

The event $\overline { \mathrm { E } }$ , representing ‘not E’, is called the **complement** of the event E. We also say that E and $\overline { { \overline { { \mathrm { E } } } } }$ are **complementary** events.

(i) What is the probability of getting a number 8 in a single throw of a die?

(ii) What is the probability of getting a number less than 7 in a single throw of a die? **Let us answer (i) :**

We know that there are only six possible outcomes in a single throw of a die. These outcomes are 1, 2, 3, 4, 5 and 6. Since no face of the die is marked 8, so there is no outcome favourable to 8, i.e., the number of such outcomes is zero. In other words, getting 8 in a single throw of a die, is impossible.

So,

$$
\mathrm{P}(\mathrm{getting}\ 8)=\frac{0}{6}=0
