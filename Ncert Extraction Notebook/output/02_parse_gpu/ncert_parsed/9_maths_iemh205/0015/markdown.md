But why does ${ } ^ { \circ } m ^ { \flat }$ represent the slope? To understand this let us consider two points $\mathrm { A } ( x _ { 1 } , y _ { 1 } )$ and $\mathrm { B }   ( x _ { _ 2 } ,   y _ { _ 2 } )$ which lie on the line $y = m x + d .$ Since they satisfy the equation we get, $y_{1} = mx_{1} + d$ and $y_{2} = mx_{2} + d.$

Now, the slope of the line passing through the points A and B is

$$
\frac{y_{2}-y_{1}}{X_{2}-X_{1}}=\frac{(mx_{2}+d)-(mx_{1}+d)}{X_{2}-X_{1}}=\frac{mx_{2}-mx_{1}}{X_{2}-X_{1}}=\frac{m(x_{2}-x_{1})}{x_{2}-x_{1}}=m
$$

This is the reason why we can just read off the slope of a line if its equation is in the form $y = m x + d .$ This also shows that the slope m of a line with equation $y = m x + d$ is given by $\frac { y _ { _ 2 } - y _ { _ 1 } } { X _ { _ 2 } - X _ { _ 1 } }$ for any two points $( x _ { 1 } , y _ { 1 } )$ and $( x _ { \mathrm { { 2 } } } , y _ { \mathrm { { 2 } } } )$ on the line, regardless of which points they are.

Note that the standard form of the equation of a line $ax + by + c = 0$ can be rewritten as

$$
by = -ax - c   or   y = -\frac{a}{b}x - \frac{c}{b}, (b \neq 0)
$$

which is of the form $y = m x + d .$ Here $m = - \frac{a}{b} \bmod d = - \frac{c}{b}.$ Hence $y = mx + d$ is another form of expressing the linear equation $ax + by + c = 0$ , provided $b \neq 0 .$ .

Consider the line $5x + y = 3$ . Rewrite it as y = –5x + 3. Can you now find its slope? What does it mean?

In $y = - 5x + 3, m = - 5$ is the slope, which means for every increase of 1 unit in x, y decreases by 5 units. d = 3 is the y-intercept which means the line crosses the y-axis at (0, 3).
