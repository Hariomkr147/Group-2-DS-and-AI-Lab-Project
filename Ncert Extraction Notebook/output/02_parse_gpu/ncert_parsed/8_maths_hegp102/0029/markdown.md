Find a partner to play this game with. In 10 seconds, the person who writes a number or an expression, using only the digits 0 - 9 and arithmetic operations, that gives a number that is the larger between the two wins the round.

10000000000000

999999×999999

In Round 1, Roxie wrote 10000000000000 and Estu wrote 999999 × 999999. Between these two, Roxie’s number is greater. Can you see why? Roxie’s number is $1 0 ^ { 1 3 }$ , whereas Estu’s number is less than $\left( 1 0 ^ { 6 } \right) ^ { 2 }$

In Round 2, Roxie wrote $1 0 ^ { 1 0 0 0 } + 1 0 ^ { 1 0 0 0 } + 1 0 ^ { 1 0 0 0 } + 1 0 ^ { 1 0 0 0 }$ and Estu wrote $( 1 0 ^ { 1 0 0 0 0 0 } ) \times 9 0 \dot { 0 } 0$ . Can you say which is greater?

$$

$$

(ii) Exponents are not allowed. Only addition and multiplication are allowed.
