If the ratio in which P divides AB is k : 1, then the coordinates of the point P will be

$$
\left( \frac{kx_{2} + x_{1}}{k + 1}, \frac{ky_{2} + y_{1}}{k + 1} \right).
$$

Special Case : The mid-point of a line segment divides the line segment in the ratio 1 : 1. Therefore, the coordinates of the mid-point P of the join of the points $\mathrm { A } ( x _ { 1 } , y _ { 1 } )$ and $\mathbf { B } ( x _ { 2 } , y _ { 2 } )$ is

$$
\left( \frac{1 \cdot x_{1} + 1 \cdot x_{2}}{1 + 1}, \frac{1 \cdot y_{1} + 1 \cdot y_{2}}{1 + 1} \right) = \left( \frac{x_{1} + x_{2}}{2}, \frac{y_{1} + y_{2}}{2} \right)
$$
