Example 4 : Find the roots of the quadratic equation $6x^{2}-x-2=0$

Solution : We have

$$
\begin{aligned}6x^{2}-x-2&=6x^{2}+3x-4x-2\\&=3x\left(2x+1\right)-2\left(2x+1\right)\\&=(3x-2)(2x+1)\end{aligned}
$$

The roots of $6x^{2}-x-2=0$ are the values of x for which $(3x - 2)(2x + 1) = 0$ Therefore, $3x - 2 = 0$ or $2 x + 1 = 0$

i.e.,

$$
x = { \frac { \stackrel { \cdot } { 2 } } { 3 } } \quad { \mathrm { o r } } \quad x = - { \frac { 1 } { 2 } }
$$

Therefore, the roots of $6x^{2}-x-2=0\  are \ \frac{2}{3}\  and \ -\frac{1}{2}$

We verify the roots, by checking that $\frac{2}{3}$ and $-\frac{1}{2}$ satisfy $6x^{2}-x-2=0$

$$

$$

Now, $\sqrt{3}x - \sqrt{2} = 0$ for $x   =   { \sqrt { \frac { 2 } { 3 } } }$
