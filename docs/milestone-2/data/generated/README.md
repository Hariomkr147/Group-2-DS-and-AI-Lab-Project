# generated

Files written by an AI assistant and reviewed by the team (not produced by a script from raw data).

- `test_scenarios/`: labelled evaluation sets (backtracking, misconceptions, guardrails) made by `build_scenarios.py`; never used for training or tuning.
- `ncert/specs.py`: concepts, prerequisite links and practice questions for the NCERT course packs. Contains no textbook text.
- `ncert/chapter_titles.csv`: verified chapter titles, used by `build_chapter_titles.py`.
